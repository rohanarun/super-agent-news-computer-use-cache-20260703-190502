How Super’s computer-use cache works

1. Observe real computer use

Super agents operate real browsers and desktops — logging clicks, keystrokes, waits, and confirmations.

2. Store successful traces

Completed workflows are stored as a reusable computer-use cache instead of being recomputed each run.

3. Reuse and adapt

Future runs replay or adapt cached actions, improving reliability for logins, navigation, and multi-step flows.

4. Human-in-the-loop

Actions that require confirmation stay assisted — no unsupported promises about purchases or payments.

Why cache matters for real agents

Without cache

  • Every run re-discovers UI
  • Higher cost for repeats
  • Fragile on minor UI changes

With Super

  • Action traces reused
  • Lower marginal cost over time
  • More stable repeated runs
